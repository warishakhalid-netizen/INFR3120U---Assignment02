## About My Project

For this assignment, I created a personal portfolio website using Express.js, Node.js, and EJS. My website has four pages: Home, About Me, Projects, and Contact Me.

The website includes information about myself, my education, skills, and projects. I also added a contact form that opens an email draft when someone clicks Submit.

## How My Website Works

I used Express Generator to create the project structure with EJS as the view engine.

- `app.js` sets up the Express application.
- `server.js` starts the server.
- `routes/index.js` contains the routes for each page.
- `views` contains my EJS pages and shared header, navbar, and footer.
- `public` contains my images, CSS, and JavaScript files.

I used Bootstrap to create the layout, navigation bar, project cards, and contact form. Font Awesome was used for icons throughout the website.

I used GitHub to track my changes and Render to host the website online.
